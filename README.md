# Best Cars Dealership - Full Stack Developer Capstone

## Repository Name
xrwvm-fullstack_developer_capstone

## Project Name
Best Cars Dealership Full Stack Application

## Project Description
This is the IBM Full Stack Software Developer Capstone project. It is a full stack web application for Best Cars, a national car dealership in the U.S. Users can view dealership branches, read reviews, and post reviews for dealers.

## Technologies Used
- Django (Python)
- React
- Node.js and Express
- MongoDB and SQLite
- Flask (sentiment analysis microservice)
- Docker, Kubernetes, IBM Cloud Code Engine
- GitHub Actions (CI/CD)
